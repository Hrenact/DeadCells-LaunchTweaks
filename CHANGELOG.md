# Changelog

## 1.0.0 - 2026-09-16

- Initial release of DeadCells-LaunchTweaks.
- Added the `-All` aggregate Steam launch option.
- Added `-SkipIntro`, `-NoNewsWindow`, `-NoControllerWarning`,
  `-NoDailyLeaderboard`, and `-NoTitleBanner`.
- Supports both the default and OpenGL Dead Cells launch choices.
